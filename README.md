# MatrAIx Healthcare Access Report

An interactive report exploring healthcare-access patterns in responses from **900 simulated personas generated from the MatrAIx dataset**.

[Open the interactive report](https://qxh2001.github.io/matraix-healthcare-report/)

## What to explore

- Reported cost, time, distance, and service-availability barriers.
- Comparisons by persona cohort, including regional and rural/urban views.
- The report's persona construction process, questionnaire routing, denominators, and methodology notes.

The report describes nine comparison groups spanning North, Central, and South India and three age bands, with 100 simulated personas in each group. It also describes using public demographic and household-consumption sources to contextualize the personas. The report's own methods and audit notes are the primary explanation of those choices.

## How to interpret it

These are **synthetic responses**, not a survey of 900 real people. Percentages describe this simulated sample and the applicable question denominators; they do not establish real-world population prevalence, clinical validity, or causal effects.

Use the artifact to explore hypotheses and identify questions for real user research. Regional comparisons combine differences in cohort composition with other background factors. Review denominators and skipped/inapplicable responses before comparing figures.

## Open offline

Download or clone the repository, then open `index.html` in a browser. The HTML contains its presentation logic and report data and can be used offline. Use the report's **Print / Save PDF** control for a printable version.

## Repository scope

This repository publishes the report artifact, not the complete persona-generation pipeline or raw source datasets. Reproducing the underlying simulated responses requires those inputs and a documented generation procedure; opening the HTML reproduces the report presentation only.
